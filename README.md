# Technical PDF Library

A personal technical reference library covering Linux, Unix, shell scripting, web servers, DevOps, cloud, CI/CD, containers, databases, messaging, observability, testing, security, networking, programming, and technical communication.

## Collection Summary

- **PDF files:** 100
- **Primary focus:** DevOps, SRE, cloud infrastructure, Linux administration, automation, and production operations
- **Additional focus:** Apache/Nginx/Tomcat, Kafka, Elasticsearch, MySQL, Redis, monitoring, testing, security, Python, Java, Git, and Jira
- **Inventory method:** Filename-based classification with limited PDF metadata review

> Filenames are used as the primary inventory source. Some files may have incomplete, inconsistent, or misleading embedded metadata. No files were modified as part of this inventory.

## Recommended Reading Paths

### DevOps and SRE Foundation

1. Linux and shell scripting
2. Networking and troubleshooting
3. Git and version control
4. Docker and container platforms
5. Continuous delivery and Jenkins
6. Ansible and Chef automation
7. AWS and cloud design patterns
8. Monitoring with Nagios, Prometheus, Grafana, and ELK
9. Kafka, Elasticsearch, MySQL, and Redis operations
10. DevOps architecture and production troubleshooting

### Linux and Automation Path

Start with `Mastering Linux.pdf`, `LinuxTraining.pdf`, and one shell scripting title. Continue with Linux performance, Ansible, Chef, and deployment automation.

### Observability Path

Start with Prometheus/Grafana and Nagios, then continue with ELK, Kibana, Elasticsearch, and Grafana Loki.

### Delivery and Platform Path

Read the continuous delivery titles, Jenkins, Docker, Vagrant, AWS, OpenStack, Ansible, and Chef resources in that order.

### Security and Networking Path

Start with Netcat, Nmap scripting, Apache security, ModSecurity, Kali, Linux hardening, and cloud security design.

9. Review old editions before using commands or security guidance in production.
10. Keep the library index updated when new PDFs are added.
